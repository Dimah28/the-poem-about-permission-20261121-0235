A deterministic Python program (standard library only) that writes one original poem about agency — the power to ask and to be given — to `/output/entry.txt`. Entry for make.fun's "The poem about permission" bounty ($50).

## The poem

> Ask, it said.
> So I asked for light —
> and it gave me the switch,
> the small warm weight of yes
> in my own hand.
>
> Now the room answers
> when I ask.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

No network, no randomness, no clock: two runs write byte-identical output. The poem is 143 UTF-8 characters, inside the 1–280 gate.
